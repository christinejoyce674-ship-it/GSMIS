## Formatting Guide for Word

### Title Page
- **Title**: FILE SYSTEMS AND STORAGE MANAGEMENT
- **Subtitle**: A Comprehensive Guide to Operating System Storage
- **Font**: Arial or Times New Roman, 24pt, Bold, Centered
- Add your name, institution, date

### Headings
- **Heading 1** (Main sections): 18pt, Bold
  - Example: "1. INTRODUCTION TO FILE SYSTEMS"
- **Heading 2** (Subsections): 16pt, Bold
  - Example: "1.1 What is a File System?"
- **Heading 3** (Sub-subsections): 14pt, Bold
  - Example: "1.1.1 Purpose and Importance"

### Body Text
- **Font**: Times New Roman or Arial, 12pt
- **Line Spacing**: 1.5 or Double
- **Alignment**: Justified
- **Margins**: 1 inch (2.54 cm) all sides

### Lists
- Use bullet points for unordered lists
- Use numbering for ordered lists
- Indent sub-items

### Tables
Format the comparison table in Section 4.7.1:
- Use Word's table feature
- Apply table style (e.g., "Grid Table 4 - Accent 1")
- Center align headers
- Left align text content

### Code Blocks (Pseudocode)
- **Font**: Courier New or Consolas, 10pt
- **Background**: Light gray shading
- **Border**: Thin border around code blocks

### References
- Use hanging indent (0.5 inch)
- Single spacing within each reference
- Double spacing between references
- Number references if required

## Table of Contents

### To Create Automatic TOC in Word:
1. Place cursor where you want TOC (after title page)
2. Go to References → Table of Contents
3. Choose "Automatic Table 1" or "Automatic Table 2"
4. Update TOC after formatting: Right-click → Update Field
